# 🚀 My Project Starters

A collection of ready-to-use configurations for quickly starting new projects.
Each configuration is stored in a separate branch.

## 🚀 How to Use

1. **Create an empty folder** or clone a new repository:

    ```bash
    mkdir my-new-app
    cd my-new-app
    git init
    ```

2. Deploy the required template (replace `#branch` with the branch name):

    ```bash
    npx degit https://github.com/atoptun/starting-templates#react/goit-neo-react-hw . --force
    ```

3. Install packages

    ```bash
    npm install
    ```

    ```bash
    corepack enable
    pnpm install
    ```

4. Enjoy
